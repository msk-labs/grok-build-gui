Grok Build CLI 的桌面图形界面

Grok Build 本身是一个终端 agent。Grok Build GUI 在它前面放上一层真正的桌面界面 —— 会话侧栏、带工具卡片的流式对话、权限确认弹窗、可被 agent 操控的内置浏览器、终端和文件树 —— 而不重新实现 agent 本身。

MIT 开源 macOS（Apple 芯片） Windows 10/11 Electron 42 React 19 ACP 协议
下载最新版本 在 GitHub 上查看源码

它是客户端，不是第二个 agent

应用会还原一个版本固定、带完整性校验的 grok 可执行文件，拉起 grok agent stdio，并通过 Agent Client Protocol（ACP） 驱动每一次会话。会话、工具和循环的唯一事实来源始终是 agent 本身； GUI 负责的是呈现、本地系统能力，以及 ACP 所要求的人工确认界面。

功能

终端能给你的全部，加上终端给不了的部分。

流式对话

逐轮导航、轮次导轨、回溯到指定位置。Markdown 与语法高亮、内联图片附件与灯箱预览。

工具卡片与 diff

每次工具调用都可展开查看参数、结果和统一格式 diff，并有文件变更条汇总这一轮改动了什么。

权限确认弹窗

实现 ACP 的 request_permission 反向请求：agent 发问，你逐次允许或拒绝 —— 从逐项确认到完全放开（YOLO）都可选。

可被 agent 操控的浏览器

内置 webview 面板以 MCP 工具服务的形式暴露给 agent。每一步操作你都看得见； 密码输入框永远会停下来单独请求确认，且密文在权限载荷中被脱敏。

终端与文件树

真实 PTY 会话（node-pty + xterm.js），可配置 shell；文件树与查看器支持 在访达中显示、以其他应用打开。

Git worktree 隔离

可以从任意分支为一次对话开一个独立 worktree，agent 的改动不会碰到你的工作副本； 应用会跟踪状态并负责清理。

截屏与语音输入

整屏、窗口或拖选区域（支持多区域）截图，带编辑器，直接作为附件进入输入框； 以及按住说话的语音转文字。

提示排队与上下文计量

一轮还在跑的时候可以继续打字排队追问，也可以中途插话。上下文计量把窗口拆成 缓存前缀、新输入、回复、思考 token 和剩余空间。

会话与工作区

会话按项目分组，可搜索、重命名、恢复，加载时把历史流式补回； 工作区选择器带最近项目和临时任务工作区。

账号与插件

通过 CLI 的 OAuth 流程登录 Grok，显示账号与用量配额； 插件可列出、安装、启用、禁用、卸载。

中英文界面

界面语言支持简体中文与英文，也可以跟随系统。

自动更新

按构建选择是否开启，来源可以是 GitHub Releases 或任意静态更新源。 另有系统代理检测、窗口状态记忆和原生应用菜单。

架构

  • 渲染进程 → 主进程。渲染进程不持有任何特权句柄。 agent 提示、终端字节流、文件读取、屏幕截图，全部经由 contextBridge 预加载层进入主进程。
  • 主进程 → agent。主进程拉起版本固定的 grok agent stdio，通过它的 stdio 管道讲 ACP。 会话状态、工具执行和目标循环都在 agent 里。
  • agent → 浏览器。主进程在随机端口上启动一个带随机 32 字节 bearer token 的回环 HTTP 桥，然后把一个 MCP 服务描述符交给 agent。agent 把该 MCP 服务作为自己的 stdio 子进程拉起，子进程再把 browser_* 调用通过那条带鉴权的回环桥转发回来， 驱动你正在看的 webview。agent 从不直接接触渲染进程。
  • 两层安全。应用层权限（ACP request_permission → GUI 弹窗） 是这个应用实现的那一层。可选的操作系统沙箱（Seatbelt/Landlock）由 agent 强制执行， 违反时直接以 EPERM 失败。

安装与运行

需要 Node.js 22.12 以上。预编译安装包在 Releases 页面； 从源码运行：

macOS

git clone https://github.com/msk-labs/grok-build-gui.git
cd grok-build-gui
./bootstrap --start

Windows

git clone https://github.com/msk-labs/grok-build-gui.git
cd grok-build-gui
.\bootstrap.cmd --start

bootstrap 会安装锁定的 npm 依赖，并还原 config/runtime/ 中声明的确切运行时版本。下载下来的运行时文件放在 thirdparty/，永远不会被提交。

常见问题

Grok Build 有图形界面吗？

Grok Build 本身是终端 agent，xAI 没有提供官方桌面 GUI。 Grok Build GUI 是一个第三方开源桌面客户端，通过 ACP 驱动同一个 CLI。

这是 agent 的一个 fork 吗？

不是。它是客户端。它拉起官方的、版本固定的 grok 可执行文件并通过 stdio 与之通信； 会话、工具和循环依然归 agent 所有。

支持哪些平台？

Apple 芯片的 macOS，以及 x64 或 ARM64 的 Windows 10/11。 Linux 的平台标识已在运行时清单中预留，但在固定产物 URL、大小和 SHA-256 校验值补齐并验证之前仍不受支持。

免费吗？

免费。GUI 采用 MIT 许可。随包的 Grok Build 产物是 Apache-2.0 并附带上游及第三方声明； Open Computer Use 0.2.1 是 MIT 许可。

怎么防止 agent 做出你不想要的操作？

agent 标记的每一次工具调用都会走 ACP 权限请求，在界面上表现为一个逐次允许或拒绝的弹窗。 内置浏览器里的密码框永远会停下来请求确认，且密文在权限载荷被展示或记录之前就已脱敏。

Grok Build GUI 是一个独立的开源项目，与 xAI 无从属关系，未获其背书或赞助。 “Grok” 是其各自权利人的商标。
